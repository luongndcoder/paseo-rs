## Known gaps and risks

- Rust daemon is not runnable end to end: paseod fronts the TS daemon (P2) and hosts core pieces in tests, but there is no cutover (P6) and several handlers have no production caller (MCP guard, set_subscription).
- Voice and dictation e2e cannot be validated on this machine (5 daemon-client failures are environmental); Rust `paseo-speech` is covered by unit tests only.
- Two single-writer risks from `docs/p4-core-spec.md` section 15 remain relevant while both runtimes read `$PASEO_HOME` (unknown keys stripped on TS rollback; skills dirs and `config.json` need a single owner per flag).
- Rust workspace needs about 47 GB of build output for debug + test; CI cost and disk pressure are real.
- Provider live tests (`*_live`, ignored) were not run, so native providers are verified against recorded traffic only.
- Several wave-2 fixes were committed with a pathspec that swept in earlier uncommitted work (`073ea68`: 81 files under `paseo-core`; `d871e7b`: 44 files in core + paseod), so those commits are larger than their messages say.
